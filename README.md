# Бот «Школьный помощник»

Бот создан для удобства получения актуальной школьной информации.
С его помощью ученики и учителя могут узнавать расписание классов,
временные изменения в расписании, информацию о классах и учителях,
а также имеют возможность одними из первых читать новости школы со страницы во ВКонтакте.

## Локальное тестирование

В директории `local` находится файл `local_server.py`, который запускает локальный сервер для тестирования бота.

Инструкция по установке и запуску сервера находится в файле [local/README.md](local/README.md).
